# The Corham, Plot 15

Interactive 3D home tour for Plot 15 at Colston Gardens, Cotgrave.

Live: https://nottsaifuture.github.io/Corham/

Drag to orbit, scroll to zoom. Choose a floor to see inside, or start the
walkthrough and use W A S D with the mouse to look around.

This repository holds the published site only. Third-party library licences
are listed in THIRD-PARTY-LICENSES.md.
